# 使用教程 · 代理 IP 切换器

> 面向第一次使用的人，从零到能换 IP，全程大约 5 分钟。

---

## 0. 先理清两个角色

| 组件 | 角色 | 你需要做什么 |
|---|---|---|
| 浏览器扩展（代理执行器） | 真正动手改浏览器代理的"手" | 装一次，之后不用管 |
| 油猴脚本（proxy-switcher.user.js） | 面板 / 配置 / 日志的"大脑" | 日常只用它 |

> 只装油猴不行（浏览器不给脚本改代理的权限）；只装扩展也不行（没有界面）。
> **两个都要装。**

---

## 1. 安装

### 1.1 安装 Tampermonkey（油猴）

- Chrome / Edge 应用商店搜索 **Tampermonkey** 安装；
- 安装成功后浏览器工具栏会出现一个黑色小图标。

### 1.2 安装浏览器扩展「代理执行器」

**方式 A：从 zip 安装（推荐给普通用户）**

1. 下载仓库里的 `dist/proxy-extension.zip` 并解压到任意固定文件夹（**不要删**，扩展要从这里加载）；
2. Chrome 打开 `chrome://extensions/`，Edge 打开 `edge://extensions/`；
3. 右上角打开 **开发者模式**；
4. 点 **加载解压缩的扩展**，选择解压出来的文件夹；
5. 列表出现「代理执行器（供油猴脚本调用）」即成功。

**方式 B：直接加载源码目录（推荐给开发者）**

克隆/下载本仓库，把 `extension/` 目录按上面第 4 步加载即可。

> 常见报错：
> - 「清单文件缺失或不可读」→ 选错文件夹了，要选包含 `manifest.json` 的那层
> - 加载后什么都没发生 → 正常，这个扩展没有界面，不用管它

### 1.3 安装油猴脚本

任选其一：

- **在线安装**：浏览器打开
  `https://raw.githubusercontent.com/zmxiaoyao/proxy-extension/main/proxy-switcher.user.js`
  Tampermonkey 会自动弹出安装页 → 点「安装」；
- **本地安装**：把 `proxy-switcher.user.js` 拖进浏览器窗口。

安装后，任意网页右下角会出现**悬浮面板**。

## 2. 首次配置

点面板上的「⚙ 配置」：

### 2.1 选择服务商

下拉可选：**熊猫代理 / 快代理 / Thordata / IPFoxy / 自定义**。
选好后，提取链接输入框的 placeholder 会显示该服务商的格式示例。

### 2.2 粘贴提取链接

去你购买代理的服务商后台，找到 **API 提取链接**（也叫"生成链接/提取链接"），整条复制粘贴进来。

| 服务商 | 返回格式示例 | 建议认证方式 |
|---|---|---|
| 熊猫代理 | `ip:port 账号 密码` 或 `ip:port` | 账号密码 + 自动读取 |
| 快代理 | `IP:Port`；或 `u125.kdltpspro.com:15818:账号:密码` | 白名单 / 账号密码 + 自动读取 |
| Thordata | `101.32.170.45:21690` | 白名单 |
| IPFoxy | `账号:密码@gate.ipfoxy.com:58688` | 账号密码 + 自动读取 |

> ⚠️ 链接里的 `secret` 等同账号权限，**别发给任何人、别提交到公开仓库**。

### 2.3 选择认证方式

| 你的情况 | 选这个 |
|---|---|
| 服务商后台已把你的 IP 加入**白名单** | 白名单 |
| 提取结果里自带账号密码 | 账号密码 + 自动读取 |
| 想让脚本用固定账密 | 账号密码 + 手动填写 |

> 切换认证方式时，脚本会同步修改链接里控制"是否返回账密"的参数
> （熊猫 `returnAccount`、快代理 `generateType`），**只在参数已存在时才改**。

### 2.4 保存

点「保存」。配置持久化在本机，换页不丢。

## 3. 日常使用

### 3.1 换 IP

- 面板点 **「🔄 换 IP」**，或
- 油猴菜单（Tampermonkey 图标）→「换 IP」

换完自动探测：**通且 ≤3000ms → 采用**；不通或太慢 → 自动换下一个（默认最多试 3 个）；
全部不合格 → **自动恢复直连**（不会让你断网）。

### 3.2 验证出口

- 面板点 **「🌐 当前 IP」** 打开验证页，或
- 手动访问 `whatismyip.com.tw`

> **重要：换 IP 后要刷新查询页**，页面不会自动重取。

### 3.3 改回直连

面板点 **「🔌 直连」**：清除浏览器代理，恢复本机网络。

### 3.4 自动轮换

配置里设置间隔（如 300 秒）后开启；不需要时关闭即可。

### 3.5 读懂日志

```
✅ 当前出口 → 1.2.3.4:8080（认证：user***） | 响应 420ms（第 2 个才合格） | 累计换 5 次
```

- `（第 2 个才合格）`：第一个不合格，换了 2 次才成
- `⚠️ 本次 IP 与上一个相同`：提取过快被限流，建议延长间隔
- `❌ 提取接口失败`：链接过期 / 白名单未配 / 被限流——换下一个也解决不了，先修链接

## 4. 进阶玩法

### 4.1 新增服务商

编辑 `proxy-switcher.user.js` 顶部的 `PROVIDERS`，加一项即可（格式见文件内注释）。

### 4.2 与自动化脚本联动（三处调用）

```js
// 1) 任务开始
await ProxyIP.startHeartbeat();

// 2) 每次访问前（二选一）
await rotateIP();               // 每次都换（最干净，最费额度）
await ProxyIP.rotateIfStale();  // 快到期才换（最省额度）

// 3) 任务结束
stopHeartbeat(); await stopProxy();
```

### 4.3 省额度参考

每次 rotate 扣 1 条（以 4 元 / 1000 条计）：

| 策略 | 1000 条线索开销 |
|---|---|
| 每条都换 | ≈ 4 元 |
| 每 20 条换一次 | ≈ 0.2 元 |
| `rotateIfStale()` 快到期才换 | 最少（≈1.15 元/天 @12条/小时） |

## 5. 故障排查表

| 症状 | 原因 | 处置 |
|---|---|---|
| 面板提示"执行器未就绪" | 扩展重载/更新后桥接失效 | **刷新当前页面** |
| 换了 IP 但网站还认旧 IP | 页面缓存 / keep-alive | 刷新页面或新开标签 |
| 一直"换不出可用 IP" | 链接失效 / 限流 / 目标探测被墙 | 看日志区分，先修链接 |
| 日志频繁"与上一个相同" | 提取过快 | 增大间隔 / 开去重 |
| 装完扩展列表没出现 | 选错文件夹 | 重选含 `manifest.json` 的目录 |
| 登录态掉线 | 换 IP 断 TCP | 重新登录（正常现象） |
| 想看 WebRTC 是否泄漏 | — | 访问 `https://browserleaks.com/webrtc` 验证 |

## 6. 安全与合规

- 所有配置（链接、账密）只存在**你自己的浏览器**，仓库里没有任何敏感数据；
- 请勿把带 `secret` 的链接提交到公开仓库或分享；
- 本工具适用于授权测试、多地域验证、隐私保护等场景；
  用它规避平台风控可能违反平台服务协议，批量访问请确认合法性并控制频次。
