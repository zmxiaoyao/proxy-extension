# 代理 IP 切换器（纯换 IP）

浏览器出口 IP 一键切换工具：**油猴脚本（面板/配置/日志） + 浏览器扩展（代理执行器）** 双件套。

> 只做一件事：换浏览器出口 IP。不含任何采集/抓取逻辑。

## ✨ 功能特性

- 🔄 **换 IP** —— 换完自动探测可用性，不通/太慢自动换下一个
- 🔌 **改回直连** —— 一键清除代理，恢复本机网络（不会留死代理）
- 🌐 **查看当前 IP** —— 一键打开 whatismyip.com.tw 验证出口
- ⏱ **自动轮换** —— 可设间隔（默认关闭）
- ⚙ **多服务商** —— 熊猫代理 / 快代理 / Thordata / IPFoxy / 自定义
- 🧾 **日志面板** —— 带时间戳，可复制 / 清空
- 🛡 **WebRTC 防泄漏** —— 自动处理

## 📦 安装（两件都要装）

### ① 浏览器扩展（代理执行器）

任选其一：

- **方式 A（推荐）**：下载 [`dist/proxy-extension.zip`](dist/proxy-extension.zip) 解压
- **方式 B**：直接使用仓库内 [`extension/`](extension) 目录

然后打开 `chrome://extensions/`（Edge 为 `edge://extensions/`）→
开启**开发者模式** → **加载解压缩的扩展** → 选择解压出的文件夹。

> 装完不用打开它、不用配置它——它是零配置哑执行器。

### ② 油猴脚本（主控面板）

1. 确保已安装 [Tampermonkey](https://www.tampermonkey.net/)（油猴）
2. 安装脚本：[`proxy-switcher.user.js`](proxy-switcher.user.js)
   - 在线安装：`https://raw.githubusercontent.com/zmxiaoyao/proxy-extension/main/proxy-switcher.user.js`
   - 或下载文件后拖入浏览器安装
3. 打开脚本顶部的配置，粘贴你自己的**代理提取链接**即可使用

## 🚀 快速开始

1. 装好扩展 + 脚本（见上）
2. 点浮动面板里的「配置」，选择服务商并粘贴提取链接
3. 点「换 IP」，等待日志显示 `✅ 当前出口 → x.x.x.x:port`
4. 去 `whatismyip.com.tw` 或日志里的入口验证（**换 IP 后要刷新页面**）

## ⚙️ 配置速查

| 配置 | 说明 | 默认 |
|---|---|---|
| 服务商 | 熊猫 / 快代理 / Thordata / IPFoxy / 自定义 | 熊猫代理 |
| 提取链接 | 服务商后台生成的 API 链接（含 token，勿外泄） | 空 |
| 认证方式 | 白名单 / 账号密码自动读取 / 账号密码手动 | 白名单 |
| 最多换几个 | 拿到 IP 不可用时重试次数 | 3（上限 10） |
| 超时阈值 | 探测响应时间上限 | 3000 ms（下限 200） |
| 探测地址 | 轻量探测目标 | 百度 favicon |
| 自动轮换间隔 | 定时自动换（默认关） | — |

**认证方式怎么选**：

- 服务商后台做了**白名单授权** → 选「白名单」
- 提取返回带账号密码 → 选「账号密码 + 自动读取」
- 想用固定账密 → 选「账号密码 + 手动填写」

## 🧭 工作原理（为什么不能纯油猴）

| 能力 | 油猴脚本 | 浏览器扩展 |
|---|---|---|
| 改浏览器代理（`chrome.proxy`） | ❌ 不暴露 | ✅ |
| `GM_xmlhttpRequest` 的 `proxy` 参数 | ❌ 仅 Firefox | — |
| 页面导航走代理 | ❌ | ✅ |

浏览器代理只能由扩展修改，这是 Chromium 的架构限制。
所以：**扩展压成零配置哑执行器，日常只用维护一个油猴脚本**。
两者通过 `window.postMessage` 通信（油猴沙箱与扩展 content script 处于不同 isolated world）。

## ❓ 常见问题

- **换完 IP 还是显示旧 IP？** 页面不会自动重取，刷新即可。
- **提示"执行器未就绪"？** 扩展重载/更新后需要**刷新页面**让桥接脚本重新注入。
- **提取失败 / 一直换不出可用 IP？** 检查：链接是否过期、白名单是否配置、是否被限流（日志出现"本次 IP 与上一个相同"即限流征兆）。
- **登录态掉了？** 换 IP 会断开已有 TCP 连接，属正常现象。
- **能否把提取链接写死在脚本里？** 不建议——链接里 `secret` 等同账号权限。本项目**不预填任何链接**。

## 🔐 安全与合规

- 仓库内**不含任何账号、token、提取链接**；所有配置都存在你自己的浏览器里
- 提取链接等同账号权限，请勿提交到公开仓库或分享
- 本项目用于授权测试、多地域验证、隐私保护等场景；用它规避平台风控可能违反平台服务协议，批量访问前请确认数据来源合法、频次合理
