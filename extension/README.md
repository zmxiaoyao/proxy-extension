# 一个脚本 + 一次安装

## 为什么不能纯油猴

| 能力 | 油猴脚本 | 浏览器扩展 |
|---|---|---|
| 改浏览器代理（`chrome.proxy`） | ❌ 不暴露 | ✅ |
| `GM_xmlhttpRequest` 的 `proxy` 参数 | ❌ **仅 Firefox**（官方标注 `v5.5.6233+ \\| Firefox only`） | — |
| 页面导航走代理 | ❌ | ✅ |

浏览器代理只能由扩展改，这是 Chromium 的架构限制，不是脚本写得不够巧。
所以方案是：**扩展压成零配置哑执行器（装一次，之后不用管），你要写和要改的只有一个油猴脚本。**

## 安装（各一次）

**① 扩展**：`edge://extensions/`（Chrome 用 `chrome://extensions/`）→ 开**开发者模式**
→ **加载解压缩的扩展** → 选 `代理执行器` 文件夹。装完不用打开它、不用配置它。

**② 脚本**：把 `熊猫代理换IP_单脚本版.js` 装进 Tampermonkey，改顶部 `CFG.API_URL` 一行即可。

## 脚本里能改什么（全在这一个文件顶部）

```js
const CFG = {
  API_URL: '...你的提取链接...',
  scheme: 'http',      // 协议
  ttlSec: 300,         // IP 有效期，熊猫高效代理约 5 分钟
  minGapMs: 1500,      // 两次提取最小间隔，防"提取过快"
  settleMs: 500,       // 换 IP 后静置，等旧连接释放
  heartbeatSec: 60,    // 心跳间隔
  autoStopSec: 300,    // 心跳超时自动恢复直连
  showPanel: true,     // 右下角悬浮面板
  autoStart: false
};
```

面板显示：当前 IP、剩余有效期、已换次数、错误提示，带「换 IP」「停用」按钮。
油猴菜单里也有三条命令：换 IP / 开始心跳 / 停止恢复直连。

## 接入你的采集脚本：三处

```js
// 1) 任务开始
await ProxyIP.startHeartbeat();

// 2) 访问/请求之前（二选一）
await rotateIP();                 // 每次都换
await ProxyIP.rotateIfStale();    // 快到期才换（最省额度）

// 3) 任务结束
stopHeartbeat(); await stopProxy();
```

**"脚本停了换 IP 也停"** 由两层保证：驱动权在脚本手里；心跳超时后执行器自动恢复直连。

## 省额度

每次 rotate 扣 1 条（4 元 / 1000 条）：

| 策略 | 1000 条线索的开销 |
|---|---|
| 每条都换 | 1000 条 ≈ 4 元 |
| 每 20 条换一次 | 50 条 ≈ 0.2 元 |
| `rotateIfStale()` 快到期才换 | 最少，约 12 条/小时 ≈ 1.15 元/天 |

## 注意事项

1. **换 IP 不是瞬时的**：HTTP keep-alive 旧连接可能仍走原 IP，换完建议刷新页面或新开标签。
2. **提取 API 已自动 bypass 直连**，否则提取请求自己走代理会被服务商拒绝。
3. **@grant 非 none 时必须 `unsafeWindow`**：脚本已自动处理，改桥接代码时别换成 `window`。
4. **扩展重载后要刷新页面**，否则报"执行器未就绪"。
5. **白名单授权**时不要在 CFG 里填账密；`returnAccount=1` 返回的账密会由执行器自动接管。
6. **WebRTC 已自动防泄漏**，可用 https://browserleaks.com/webrtc 验证。
7. **API 链接里的 `secret` 等同账号权限**，别外泄。
